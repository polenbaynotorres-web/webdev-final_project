# TORRES VEHICLE RENTAL - DOCKER SETUP

## Requirements

- Windows 10/11
- Docker Desktop with Docker Compose
- PowerShell

## Services and URLs

- Symfony application: http://127.0.0.1:8000
- phpMyAdmin: http://127.0.0.1:8081
- MySQL from Windows: 127.0.0.1:3308

Container names: `torres_symfony_app`, `torres_mysql`, and `torres_phpmyadmin`.

## Start the application

Open PowerShell in the folder containing `compose.yaml` and run:

```powershell
docker compose config
docker compose up -d --build
docker compose ps
docker compose logs -f app
```

The included `.env` values are local development examples only. Change the database passwords and APP_SECRET before exposing the system to a public network. Do not use sample credentials for a public deployment.

## Existing database

The database name is `torres_rental`. Docker stores data in the persistent volume `torres_mysql_data`.

If you already have your `torres_rental` database on Windows MySQL, you can continue using that database instead of importing a new copy. Configure the Symfony `DATABASE_URL` for the environment where PHP runs:

- Inside Docker: hostname `database`, port `3306`.
- From Windows: host `127.0.0.1`, port `3308` when using the Compose MySQL service, or your local MySQL port if using a separate server.

Back up your existing database before applying migrations. Review the migration files in `migrations/` and run `php bin/console doctrine:migrations:status` and `php bin/console doctrine:migrations:migrate --dry-run` before applying them. Never run `doctrine:schema:drop` on a database containing data you need.

This distributable project intentionally does not include SQL dumps or private database backups. Import no SQL file unless you are deliberately initializing an empty database and have verified the SQL contents.

## Useful commands

```powershell
docker compose start
docker compose stop
docker compose ps
docker compose logs -f app
docker compose down
```

`docker compose down` preserves the named MySQL volume. Do not use `docker compose down -v` unless you intentionally want to delete the database volume and all data stored in it.

## phpMyAdmin

Open http://127.0.0.1:8081. The server is `database`; the username and password are the local values configured in `.env`.

Keep phpMyAdmin private. Do not expose its port through ngrok.
