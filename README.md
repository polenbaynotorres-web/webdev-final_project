# Symfony Web Development Project

## Description
A web application developed using Symfony and PHP.

## Technologies Used
- PHP
- Symfony
- Twig
- Doctrine ORM
- Composer

## Installation

1. Clone this repository.
2. Install dependencies:

   ```bash
   composer install
   ```

3. Configure your environment variables in `.env.local`.
4. Start the Symfony development server:

   ```bash
   symfony server:start
   ```
